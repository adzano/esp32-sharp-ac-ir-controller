# Capture Sharp 015 — AUTO + fan AUTO

Foto remote menunjukkan mode AUTO dan fan AUTO.

```text
Protocol: SHARP_AC (104 bits)
Power: On
Mode: 0 (Auto)
Temperature state: 15C
Fan: 2 (Auto)
Overflow: false
State: AA 5A CF 10 00 31 20 00 08 80 00 E0 21
```

Layar AUTO tidak menampilkan suhu. Nilai 15°C dicatat sebagai state protokol saja.
