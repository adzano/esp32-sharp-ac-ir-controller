# Capture Sharp 016 — posisi louver vertikal High

Foto remote menunjukkan AUTO, fan AUTO, serta indikator arah hembusan di sisi kiri layar.

```text
Protocol: SHARP_AC (104 bits)
Power: On
Mode: 0 (Auto)
Temperature state: 15C
Fan: 2 (Auto)
Swing(V): 1 (High)
Overflow: false
State: AA 5A CF 10 00 31 20 00 09 80 06 E0 51
```

Tekanan pertama tombol arah hembusan mengubah posisi louver vertikal ke High. Ini belum membuktikan mode swing otomatis; posisi berikutnya perlu dipetakan satu per satu.
